# Bitfinex 融資機器人

Bitfinex 融資（放貸）自動化機器人的 domain 詞彙表。核心概念圍繞「把閒置資金放出去賺利息」與「衡量放得好不好」。

## Language

**出借 (credit)**：
把 funding 錢包的資金借給保證金交易者、換取利息的一筆合約。有開始時間、存續天數（`period`）、利率、金額。對應 Bitfinex 的 funding credit。
_Avoid_：貸款、loan（`loan` 在 Bitfinex 專指借入方，方向相反）

**可投入本金 (investment)**：
某一天可用來放貸的資金總額，等於該日 funding 錢包餘額扣掉當日剛入帳的利息。約等於前一經濟日結束時的本金。
_Avoid_：餘額、balance（balance 含當日利息，比 investment 略大）

**資金利用率 (lentRatio)**：
某段期間內「實際放出去的本金」佔「可投入本金」的比例。算法為時間加權：把每筆出借的金額依存續時間攤到每一天，再用 `Σ每日放出金額 ÷ Σ每日可投入本金 × 100%` 得到 N 日利用率。天天滿倉時 ≈ 100%；當日有大額入金時分母會滯後，可能短暫超過 100%。
_Avoid_：使用率、utilization、util（`util` 易被誤讀為「工具」）

**利息經濟日 (earning day)**：
一筆利息實際上是「哪一天放貸賺到的」。Bitfinex 每日約 00:00 UTC 發放利息 payout，這筆錢屬於**前一天**的放貸成果。因此報告掛在 payout 當天的日期標籤下，但數字反映的是前一天。
_Avoid_：入帳日、payout 日（那是收到錢的日子，不是賺到錢的日子）

**年化 (apr)**：
把某段期間的日報酬率換算成一年的報酬率，用來跨天期比較績效。報告提供 1／7／30／365 日年化。
