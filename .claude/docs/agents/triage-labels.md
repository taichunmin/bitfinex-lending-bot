# Triage 標籤

這些 skill 以五個標準 triage 角色來溝通。本檔把這些角色對應到這個 repo 的 issue tracker 實際使用的標籤字串。

| mattpocock/skills 的標籤 | 我們 tracker 的標籤 | 意義                       |
| ------------------------ | ------------------- | -------------------------- |
| `needs-triage`           | `needs-triage`      | 維護者需要評估這個 issue   |
| `needs-info`             | `needs-info`        | 等回報者補充更多資訊       |
| `ready-for-agent`        | `ready-for-agent`   | 規格完整，可交給 AFK agent |
| `ready-for-human`        | `ready-for-human`   | 需要人工實作               |
| `wontfix`                | `wontfix`           | 不會處理                   |

當 skill 提到某個角色（例如「apply the AFK-ready triage label」），就用這張表對應的標籤字串。

因為這個 repo 用本地 markdown 追蹤 issue，標籤是寫在 issue 檔案開頭附近的 `Status:` 行，例如 `Status: ready-for-agent`。

若你實際使用的詞彙不同，請修改右欄。
